CHAPTER 12 · REAL RETURN

通胀、费用和税为什么会悄悄吃掉收益？

从名义收益走向真实财富：账户里赚了多少，不等于购买力增加多少，也不等于最后真正留下多少。
预计阅读 75–90 分钟真实收益核心章4 个互动实验最终产物：真实收益地图 v1

00｜账户上涨 8%，你真的变富 8% 了吗？

不一定。因为“账户里的数字增长”只是名义层面的第一步。真正的财富结果还要经过费用、税和价格水平变化。

账户毛收益 ≠ 费用后收益 ≠ 税后收益 ≠ 真实购买力增长
以后看到任何收益率，先问三件事
Gross or Net? Nominal or Real? Pre-tax or After-tax?

01｜三层收益率：同一个“8%”可能在说完全不同的东西

Gross Nominal Return

资产本身的名义毛收益。

Net / After-Tax Return

扣除相关费用与适用税负后的结果。

Real Return

进一步考虑通胀后的购买力增长。

如果不先统一口径，两个看起来“收益率一样”的产品或策略根本无法公平比较。

02｜Inflation：不是“某一样东西涨价”

通胀描述的是总体价格水平在一段时期内的变化。国家统计局对 CPI 的解释强调，它综合反映居民消费商品和服务价格水平的总体变动。

所以某种蔬菜涨价 30%，或者某款手机涨价，并不能单独证明“整体通胀就是 30%”。

03｜CPI 到底在测什么？

CPI 需要一个具有代表性的消费篮子，并根据居民实际消费结构赋予不同类别不同权重。中国 CPI 当前覆盖食品烟酒、衣着、居住、生活用品及服务、交通通信、教育文化娱乐、医疗保健、其他用品及服务八大类。

为什么要有权重？
食品价格上涨 10% 和汽车价格不变，不能直接平均成 5%。居民花在不同类别上的钱并不一样。

04｜CPI 不等于“我的个人通胀率”

官方 CPI 描述的是代表性居民消费篮子的总体变化，但每个人的支出结构不同。大学生、育儿家庭、退休老人，对房租、教育、医疗、交通和食品的权重可能完全不同。

个人通胀估计 ≈ Σ（个人支出权重 × 对应类别价格变化）

这个“个人通胀率”只是课程规划工具，不替代官方 CPI；它帮助你理解自己的生活成本到底暴露在哪些价格变化上。

05｜真正被通胀改变的是 Purchasing Power

今天一顿饭 20 元100 元可以买 5 顿

如果未来同样一顿饭变成 25 元，同样 100 元只能买 4 顿。账户里的 100 元没有减少，但实际能够购买的东西减少了。

名义金额稳定，不等于真实价值稳定。

06｜名义金额上涨，为什么仍然可能“变穷”？

如果资产收益只有 2%，但生活成本总体上涨 3%，账户数字在增加，购买力却可能下降。这就是“名义正收益、实际负收益”。

07｜Real Return 的精确公式

1 + Real Return = (1 + Nominal Return) ÷ (1 + Inflation)

例如名义收益 8%、通胀 3%：

1.08 ÷ 1.03 − 1 ≈ 4.85%

真实购买力增长约 4.85%，不是正好 5%。

08｜为什么“收益率 − 通胀”只是近似？

因为资产上涨和价格上涨是两个比例变化，严格关系是乘除法，不是简单加减。

100 元资产涨到 108 元同时价格指数从 100 到 103

真实购买力比例是 108 ÷ 103 ≈ 1.0485，所以实际增长约 4.85%。

当收益率与通胀都较小时，直接相减通常是不错的快速估算；但知道精确关系，才能避免在高通胀或高收益环境里产生明显误差。

09｜通胀也会复利

如果价格水平每年上涨 3%，十年后不是简单增加 30%，而是：

1.03^10 ≈ 1.344
1.03^30 ≈ 2.427

换句话说，今天 100 元能购买的同一组商品，如果长期每年平均上涨 3%，三十年后可能需要约 243 元。

10｜现金最大的错觉：没有波动，所以没有风险

现金在名义层面可能非常稳定，但只要收益持续低于生活成本增长，购买力就会慢慢下降。

为第十三章提前埋一个重要概念
风险不等于“价格上下波动”。购买力下降也是一种风险。

11｜“跑赢通胀”不是所有资金的唯一目标

三个月后必须交学费的钱，第一任务可能是本金稳定和流动性，而不是承担大幅市场波动去追求跑赢 CPI。

真正应该问的是：这笔钱承担什么任务？它需要在什么风险约束下维持购买力？

12｜第二个侵蚀者：Fees

费用危险的地方在于数字很小：0.25%、0.5%、1%。但它从能够继续复利的本金中持续拿走一部分。

长期费用损失 = 当期被扣费用 + 这些费用未来原本能够产生的复合收益

13｜为什么 1% 看起来很小，长期却很大？

Investor.gov 的长期费用示例说明：同样的初始投资、相同毛回报，只因为持续费用率不同，20 年后的终值就可能拉开很大差距。

真正应该看的不是“今年只扣 1%”，而是：

如果这 1% 每年都不再参与后续复利，几十年后少掉的总财富是多少？

14｜一次性费用和持续费用不是同一种东西

Transaction Costs

买卖时发生，例如佣金、部分申购赎回费用、买卖价差。

Ongoing Costs

持有期间持续发生，例如管理费、托管费、基金运营费用等。

一次性费用影响交易时点，持续费用则会反复削弱未来可复利本金。

15｜Expense Ratio：为什么你没看到扣款，成本仍然发生了？

基金的管理、运营、行政等成本通常从基金资产中持续扣除，因此不会总以“银行卡扣 20 元”的方式出现，但会体现在基金净值和投资者最终回报里。

这也是为什么第十章的产品尽调不能只问“有没有申购费”，还要看整个持有成本结构。

16｜“0 费用”首先要问：哪一种费用是 0？

产品可以没有申购费，但仍可能有管理费、销售服务费、买卖价差、交易成本或赎回成本。

看到“零费用”不要停止阅读
0 Fee → Which Fee?

17｜费用真正应该怎样比较？

先确认两个产品是不是在完成相似任务、承担相似风险、提供相似服务，再比较总成本。否则拿一个复杂主动服务产品和一个简单指数工具，只看费率数字高低，本身也可能失去语境。

原则
Low Cost 很重要，但 Lowest Cost 并不会脱离产品任务自动成为 Best Fit。

18｜第三个侵蚀者：Tax

税收会让部分已经形成的收益离开投资系统，因此同样具有“当期扣除 + 未来复利机会减少”的双重影响。

但税务部分不能简单套一个统一税率，因为不同国家、资产、交易市场、账户和政策可能差异很大。

19｜税到底可能作用在哪一层收益？

Interest

利息类收入。

Dividend / Distribution

股息、红利及相关分配。

Capital Gain

资产转让或价格上涨后的实现收益。

真正的第一步不是背税率，而是判断：这笔收益在法律和税务上属于什么性质？

20｜中国投资税收为什么不能“一刀切”理解？

现行个人所得税法确实把利息、股息、红利所得和财产转让所得等列入应税所得类型，并规定了相应比例税率框架；但具体金融资产可能存在免税、暂免、优惠、代扣或其他特别规则。

本章只教 Tax Awareness，不做“投资税率大全”
每次都应该重新核验：资产类型、收益性质、当前政策、纳税时点、是否存在优惠或暂免。

21｜一个很好的中国现实例子：储蓄存款利息

截至 2026 年公开税务办事口径仍然明确：自 2008 年 10 月 9 日起，对储蓄存款利息所得暂免征收个人所得税。

这说明不能看到个税法中的“利息所得”税率，就直接推导“银行存款利息现在一定按统一比例扣税”。

22｜Taxable / Tax-Deferred / Tax-Exempt 是三种不同结构

Taxable

按适用规则在当前或相应时点产生税负。

Tax-Deferred

税负延后到未来某个时点。

Tax-Exempt

符合规则的收益免税。

这里学习的是结构，不照搬美国 401(k)、IRA 等具体制度。

23｜为什么“晚交税”本身也有时间价值？

税延不等于免税。它的价值来自：原本现在就要离开投资系统的钱，可以继续保留更长时间并参与复利。

Tax Deferral = More Capital Retained for Longer → More Compounding Time

这正是第十一章 Time Value of Money 在税务问题上的直接应用。

24｜Realized vs Unrealized：账面赚了不等于已经“实现”

资产从 100 涨到 120、但仍然持有，这 20 通常可以称为未实现收益；出售后才形成已实现结果。税收是否以及何时发生，很多情况下和“有没有实现”有关，但具体规则仍然依赖资产和当地制度。

25｜Turnover：频繁买卖为什么可能让毛收益很好看、净结果变差？

高换手可能增加佣金、买卖价差、其他交易摩擦，也可能更频繁触发某些税务事件。

策略真正值得比较的是投资者最终保留下来的结果，而不只是毛收益曲线。

26｜Gross Return 和 Net Return

Gross Return

尚未扣除部分管理、运营或其他相关成本之前的收益。

Net Return

扣除适用成本后更接近投资者实际获得的收益。

看基金、资管或任何投资策略的历史业绩时，必须先确认展示口径。

27｜最终真正应该关心：Real After-Tax Return

假设毛收益 8%，费用后约 7%，再考虑适用税务处理，最后才用通胀把名义结果转换成购买力结果。

Gross Nominal → Net of Fees → After Tax → Adjust for Inflation → Real After-Tax Return

这个数字更接近“我的购买力到底增长了多少”。

29｜为什么不能写成“8% − 1% − 20%税 − 3%通胀”？

因为税通常不是从全部本金直接扣一个比例，费用和税的发生方式、时点也可能不同，通胀又是对最终购买力的比例调整。

正确思路是：把每一层作用在正确的基数上，再逐层计算。

30｜四个现实案例

A｜“存款利率 2%，财富每年增长 2%”名义正 ≠ 实际正

如果生活成本上涨 3%，账户数字增加，但购买力可能下降。

B｜两个类似基金，费用差 1%Fee Drag

毛收益相同时，费用差异会逐年削弱可复利本金，长期终值差距越来越大。

C｜“利息所得税率是 20%，所以存款利息一定扣 20%”一般规则 ≠ 当前具体产品政策

中国储蓄存款利息目前仍有暂免个人所得税政策。

D｜高换手策略毛收益略高Gross Performance ≠ Investor Outcome

交易摩擦和适用税务成本可能使投资者最终留下的财富更少。

36｜Goal Inflation：你的目标金额也会“变老”

第三章如果写“五年后教育资金需要 300,000 元”，必须继续问：这是今天价格还是未来价格？

今天 300,000 元的目标成本假设专项成本每年上涨 4%

五年后的名义目标金额约为：

300,000 × 1.04^5 ≈ 365,000

教育、医疗、住房等具体目标的价格变化可能与总体 CPI 不同。所以真正的目标倒推流程应该是：

今天目标价格 → 目标专属通胀 → 未来名义目标 → 费用后/税后收益假设 → 每月需要投入

37｜如果这一章真正学会了，你应该多出这十句话

1. 名义收益不等于真实购买力增长。

2. CPI 是总体价格指标，不等于每个人的个人生活成本。

3. 实际收益的精确关系是比例关系，不只是简单相减。

4. 通胀本身也具有复合效应。

5. 没有价格波动，不代表没有购买力风险。

6. 持续费用会同时减少当前资产和未来复利本金。

7. “零费用”必须继续问到底是哪一种费用为零。

8. 税收应按具体资产、收益性质和当前规则判断，不能套统一税率。

9. Gross Return 不等于投资者最终真正留下的结果。

10. 最终真正关心的是：费用后、税后、通胀后的真实收益。
